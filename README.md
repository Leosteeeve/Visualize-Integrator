# Calculus Studio

本地优先的可视化积分学习与自动计算系统。当前目标是把“算得准”和“看得懂”放在第一位：后端用 SymPy/SciPy/C++ 做计算，前端用模板输入、书面步骤和 Canvas 可视化帮助学习。

## 当前阶段

- 顶部主导航分为：
  - **学习路线**：从零解释积分直觉、符号含义、公式来源和典型技巧。
  - **练习模式**：按积分种类和难度自动生成题目，并显示方法、步骤、答案和图像。
  - **问答模式**：用户输入自己的题目，系统解析、计算、解释并尝试可视化。
  - **可视化工具**：保留原来的积分计算器操作区，作为所有模式共用的图像舞台。
- 常见一元函数的定积分和不定积分。
- 反常积分：支持无穷上下限、端点奇点、收敛/发散提示。
- 矩形区域二重积分：支持 `x/y/z` 三轴曲面预览。
- SymPy 生成符号积分、精确定积分和 LaTeX。
- C++ 自适应 Simpson 引擎负责快速数值定积分。
- C++ 二维 Simpson 引擎负责矩形区域二重积分。
- C++ 不可用时自动回退到 SciPy `quad`。
- 浏览器界面绘制曲线、坐标轴、上下限、面积阴影，以及二重积分的 `x/y/z` 三轴曲面预览。
- 内置积分学习指南，覆盖常积分、基础积分技巧、反常积分、矩形区域二重积分。
- 章节例题和随机练习可以自动调用计算器，显示书面步骤和可视化结果。

## 学习与练习内容

学习路线目前包含四个章节：

- 从面积到积分：解释小矩形逼近、正负面积、积分符号每一部分的含义。
- 常积分与基本技巧：幂函数公式、微积分基本定理、换元法、分部积分。
- 反常积分：把无穷区间和奇点转化为极限，并判断收敛或发散。
- 二重积分：把二维区域切成小块，用曲面高度累加体积。

练习模式按四档难度生成题目：

- **简单**：直接公式、幂函数、基础三角函数。
- **AP**：换元、面积/累积量、基础反常积分。
- **高等技巧**：分部积分、恒等变形、可分离二重积分。
- **MIT/挑战**：多步骤技巧、收敛判断、数值型曲面体积、非初等闭式题。

题目不是随便拼字符串，而是由题型模板生成。模板会携带表达式、上下限、标准方法、步骤说明和可视化配置，生成后再交给后端计算验证。

## 运行

```bat
run.bat
```

然后打开：

```text
http://127.0.0.1:8000
```

后端第一次计算时会尝试自动编译 `cpp\integrator.cpp`。也可以手动编译：

```bat
build_cpp.bat
```

## 输入格式

表达式支持 `x`，二重积分支持 `x` 和 `y`：

```text
x^2
sin(x)
exp(-x^2)
sqrt(1-x^2)
log(x)
x*y
```

上下限可以使用 `pi`、`e` 和普通代数式。

反常积分可以使用：

```text
oo
-oo
```

问答模式同时支持结构化输入和少量自然数学文本，例如：

```text
∫_0^1 x^2 dx
∫_1^oo 1/x^2 dx
∫∫ x*y dA
```

复杂题推荐使用页面里的模板按钮和结构化字段输入，稳定性会比纯文本更好。

## API

底层计算接口：

```text
POST /api/integrate
```

步骤解释接口：

```text
POST /api/solve
```

示例请求：

```json
{
  "mode": "definite",
  "expression": "x^2",
  "variable": "x",
  "lower": "0",
  "upper": "1"
}
```

返回内容包括题目类型、推荐方法、精确结果、数值结果、LaTeX、步骤数组和可视化数据。

## 计算策略

- **模板题**：使用预写策略模板生成书面步骤，稳定、可控、接近教材格式。
- **自由输入题**：先用规则识别方法，再给出通用步骤；无法可靠推导完整过程时，仍返回答案、数值校验和图像。
- **符号计算**：优先使用 SymPy 获取精确表达式和 LaTeX。
- **数值计算**：优先调用 C++ Simpson 引擎，失败时回退到 SciPy。
- **前端显示**：MathJax 渲染公式；如果 CDN 不可用，页面仍会显示原始 TeX 文本并保持计算功能。
