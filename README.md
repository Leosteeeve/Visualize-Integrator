# Calculus Studio

本地优先的可视化积分计算器 MVP。

## 当前阶段

- 常见一元函数的定积分和不定积分。
- SymPy 生成符号积分、精确定积分和 LaTeX。
- C++ 自适应 Simpson 引擎负责快速数值定积分。
- C++ 二维 Simpson 引擎负责矩形区域二重积分。
- C++ 不可用时自动回退到 SciPy `quad`。
- 浏览器界面绘制曲线、坐标轴、上下限、面积阴影，以及二重积分的 `x/y/z` 三轴曲面预览。
- 内置积分学习指南，覆盖常积分、基础积分技巧、反常积分、矩形区域二重积分。
- 章节例题和随机练习可以自动调用计算器，显示书面步骤和可视化结果。

## 运行

```bat
run.bat
```

然后打开：

```text
http://127.0.0.1:8000
```

后端第一次计算时会尝试自动编译 `cpp\integrator.cpp`。也可以手动编译：

```bat
build_cpp.bat
```

## 输入格式

表达式目前使用变量 `x`：

```text
x^2
sin(x)
exp(-x^2)
sqrt(1-x^2)
log(x)
```

上下限可以使用 `pi`、`e` 和普通代数式。
